# ⭐ RateHub

A full-stack store rating platform where users can discover stores, submit ratings, and manage their reviews.

RateHub provides separate role-based experiences for **System Administrators, Normal Users, and Store Owners**, with secure authentication, store management, rating management, search, filtering, and sorting.
